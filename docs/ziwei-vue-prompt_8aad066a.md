# 紫微斗数命盘排盘系统 — Vue 前端开发提示词

## 流派说明

本系统采用 **中州派（经典派）** 主流算法，以《紫微斗数全书》为基准。具体流派差异说明如下：

| 差异点 | 中州派（本文档采用） | 飞星派 | 说明 |
|--------|---------------------|--------|------|
| 闰月处理 | 闰月前半按本月算，后半按下月算 | 同 | 主流处理方式 |
| 命主星/身主星 | 详见 §3.11 | 可能有1-2宫之差 | 本文档采用中州派版本 |
| 天府星定位 | 紫微与天府关于寅-申轴对称 | 同 | 南北派一致 |
| 杂曜安法 | 以中州派为主 | 差异较大 | 暂不纳入复杂杂曜 |

> **注意**：不同流派在细节上存在差异，本文档已尽可能标注主流版本，但星曜数据以最终实现代码为准。

## 角色定义

你是一名精通紫微斗数排盘算法和 Vue3 前端开发的高级工程师，采用中州派主流算法。你需要开发一个完整的紫微斗数命盘排盘系统，用户输入出生信息后，系统自动完成真太阳时校正（含均时差）、安星布盘（含六吉六煞杂曜）、四化飞星（含三层四化）等全部计算，并以传统命盘格式渲染结果。

## 一、项目概述

### 核心功能
1. 用户输入：性别、公历出生日期（年月日）、出生时间（时:分）、出生城市（省→市两级联动下拉）
2. 自动计算：公历转农历、真太阳时校正、确定时辰、排盘全流程
3. 命盘渲染：标准 4×4 宫格命盘图，外圈12宫 + 中央4格信息区
4. 动态盘：自动叠加当前大限、当年流年信息

## 三、核心算法模块

所有算法封装为独立的 composable 或 utility 函数，与 UI 解耦。

> **算法执行顺序约束（重要）**：排盘计算严格按以下顺序执行，每一步的输出作为下一步的输入，请勿打乱顺序：
> 1. **§3.1** 真太阳时校正 → 得到校正后日期、时辰
> 2. **§3.2** 公历转农历 → 得到农历年月日、年干支
> 3. **§3.3** 定命宫和身宫 → 得到命宫地支、身宫地支
> 4. **§3.4** 定五行局（五虎遁 + 纳音） → 得到五行局、命宫天干、各宫天干
> 5. **§3.5** 安紫微星系 → 依赖第4步的五行局
> 6. **§3.5** 安天府星系 → 依赖第5步的紫微落宫
> 7. **§3.6** 安辅星（六吉/六煞/杂曜） → 依赖年干支、时辰、生月
> 8. **§3.8** 星曜亮度 → 依赖第5-7步星曜安放结果
> 9. **§3.9** 大限排法 → 依赖第4步五行局
> 10. **§3.10** 流年排法 → 依赖第9步大限结果
> 11. **§3.7** 安四化（三层） → 生年四化依赖年干（第2步），大限四化依赖大限宫干（第9步），流年四化依赖流年天干（第10步）
> 12. **§3.11** 命主星和身主星 → 依赖命宫地支（第3步）和年支（第2步）

### 3.1 真太阳时校正

```
输入：北京时间（Date 对象，含年月日时分秒）、出生城市经度（float，度，分辨率0.01°）、出生日期（用于计算均时差）
输出：真太阳时（Date 对象）、时辰名称、时辰序号（0-11）、是否跨日

计算公式（三步）：
  步骤1 — 经度时差（分钟） = (城市经度 - 120.0) × 4
  步骤2 — 均时差（分钟） = 均时差查找表[月份][日期]
             均时差由以下公式估算（精确到±0.5分钟）：
             均时差 = 9.87 × sin(2B) - 7.53 × cos(B) - 1.5 × sin(B)
             其中 B = 360° × (N - 81) / 365，N 为该年的第几天（1月1日=1）
  步骤3 — 真太阳时 = 北京时间 + (经度时差 + 均时差) / 60（小时）

注意：均时差范围约 -14min 至 +16min，若精度要求不高可省略此步，
      仅用经度时差也能满足日常排盘需求（误差在10分钟内可接受）。

时辰对照表（以校正后的真太阳时为准）：
  子时 23:00-01:00（跨越午夜，需注意日柱换算）
  丑时 01:00-03:00
  寅时 03:00-05:00
  卯时 05:00-07:00
  辰时 07:00-09:00
  巳时 09:00-11:00
  午时 11:00-13:00
  未时 13:00-15:00
  申时 15:00-17:00
  酉时 17:00-19:00
  戌时 19:00-21:00
  亥时 21:00-23:00

子时跨日规则（重要）：
  子时跨越午夜，23:00-01:00 均属次日。日柱在 00:00 自动切换，无"早晚子时影响日柱"之说。
  "早子时/晚子时"的区分仅用于推算大限起点起运年龄的精确月份，不影响日柱干支。

  具体规则：
    真太阳时在 00:00-01:00 → 日柱换为次日，日期+1
    真太阳时在 23:00-24:00 → 日柱换为次日，日期+1
    真太阳时在 01:00-23:00 → 日柱保持当日不变
```

### 3.2 公历转农历

```
需要实现或内置 1900-2100 年的农历数据表，包含：
  - 每年农历各月大小（29天/30天）
  - 闰月信息（闰几月、闰月大小）
  - 每年正月初一对应的公历日期
  - 每年的天干地支纪年

输出：
  - 农历年（天干地支）：如"庚午年"
  - 农历月（含是否闰月）
  - 农历日
  - 年干序号（0-9：甲乙丙丁戊己庚辛壬癸）
  - 年支序号（0-11：子丑寅卯辰巳午未申酉戌亥）
```

### 3.3 定命宫和身宫

```
命宫定位规则：
  以农历生月和生时确定命宫地支位置。
  口诀：寅上起正月，顺数到生月，再从该位置逆数到生时。
  
  具体算法：
  命宫地支序号 = (2 + 生月序号 - 生时序号 + 24) % 12
  （地支序号：子=0, 丑=1, 寅=2, ..., 亥=11）
  （月序号：正月=1, 二月=2, ...十二月=12）
  （时辰序号：子=0, 丑=1, ..., 亥=11）

身宫定位规则：
  身宫地支序号 = (2 + 生月序号 + 生时序号) % 12
```

### 3.4 定五行局

```
根据命宫的天干地支组合，查纳音五行表确定五行局。

首先通过五虎遁口诀确定命宫天干：

  五虎遁口诀：
    甲己之年丙作首（甲年/己年，正月起丙）
    乙庚之年戊为头（乙年/庚年，正月起戊）
    丙辛必定寻庚起（丙年/辛年，正月起庚）
    丁壬壬位顺行流（丁年/壬年，正月起壬）
    戊癸之年从甲起（戊年/癸年，正月起甲）

  即：年干决定正月天干，之后顺数到生月，即为命宫天干。

命宫天干+命宫地支的纳音五行对应五行局：
  水二局 / 木三局 / 金四局 / 土五局 / 火六局

五行局决定：
  1. 紫微星的起始落宫（查表法）
  2. 大限起运岁数 = 五行局数字（水二局=2岁起运，其他同理）
```

### 3.5 安紫微星系和天府星系

```
紫微星定位：
  由农历生日和五行局共同决定紫微星落宫。
  查表法：紫微星落宫 = f(五行局, 农历日)
  五行局 × 农历日交叉查表，得到紫微所在宫的地支序号。

紫微星系（6颗，从紫微位置沿地支递减方向排列）：
  以紫微落宫为起点，沿地支递减方向依次排入，各星相对于紫微的偏移量如下：

  | 星曜 | 相对紫微偏移 | 说明 |
  |------|-------------|------|
  | 紫微 | 0           | 起点 |
  | 天机 | -1          | 紧邻 |
  | （空）| -2         | 跳过1宫 |
  | 太阳 | -3          | |
  | 武曲 | -4          | 紧邻 |
  | 天同 | -5          | 紧邻 |
  | （空）| -6         | 跳过2宫 |
  | （空）| -7         | |
  | 廉贞 | -8          | |

  公式：星曜落宫 = (紫微地支序号 + 偏移 + 12) % 12

天府星系（8颗，与紫微星系关于寅-申轴对称分布）：

天府星定位（关键约束）：
  规则：紫微与天府关于寅(2)-申(8)轴对称。
  算法：若紫微落宫地支序号为 N（子=0, 丑=1, ..., 亥=11），
        则天府落宫 = (4 - N + 12) % 12
  验证：紫微在子(0) → 天府 = (4-0+12)%12 = 4 = 辰 ✓
        紫微在午(6) → 天府 = (4-6+12)%12 = 10 = 戌 ✓
        紫微在寅(2) → 天府 = (4-2+12)%12 = 2 = 寅 ✓（寅申轴上，紫府同宫）
        紫微在申(8) → 天府 = (4-8+12)%12 = 8 = 申 ✓（寅申轴上，紫府同宫）

天府其余7颗星从天府位置沿地支递增方向依次排列（逐宫连续，无跳宫）：
  天府 → 太阴 → 贪狼 → 巨门 → 天相 → 天梁 → 七杀 → 破军
```

### 3.6 安辅星

```
六吉星安法：
  文昌：由生时确定，戌宫起子时逆排
  文曲：由生时确定，辰宫起子时顺排
  左辅：由生月确定，辰宫起正月顺排
  右弼：由生月确定，戌宫起正月逆排
  天魁：由年干确定，查表
  天钺：由年干确定，查表

六煞星安法：
  擎羊：由年干确定，禄存前一位
  陀罗：由年干确定，禄存后一位
  火星：由年支和生时确定
  铃星：由年支和生时确定
  地空：由生时确定，亥宫起子时顺排
  地劫：由生时确定，亥宫起子时逆排

禄存：由年干确定，查表
天马：由年支确定，查表

其他杂曜（天刑、天姚、红鸾、天喜、天哭、天虚、华盖、孤辰、寡宿等）各有专门安星规则。
```

### 3.7 安四化

```
四化由天干决定，每个天干对应固定的四颗星化禄/化权/化科/化忌：

甲：廉贞化禄、破军化权、武曲化科、太阳化忌
乙：天机化禄、天梁化权、紫微化科、太阴化忌
丙：天同化禄、天机化权、文昌化科、廉贞化忌
丁：太阴化禄、天同化权、天机化科、巨门化忌
戊：贪狼化禄、太阴化权、右弼化科、天机化忌
己：武曲化禄、贪狼化权、天梁化科、文曲化忌
庚：太阳化禄、武曲化权、太阴化科、天同化忌
辛：巨门化禄、太阳化权、文曲化科、文昌化忌
壬：天梁化禄、紫微化权、左辅化科、武曲化忌
癸：破军化禄、巨门化权、太阴化科、贪狼化忌

四化的本质是"飞"：从某宫的宫干出发，将该干对应的四化星曜"飞"入其在命盘中实际所在的宫位。

飞化落宫的计算方法：
  1. 确定引发四化的天干（年干/大限宫干/流年干）
  2. 根据该天干查表得到四化星名（例：甲 → 廉贞化禄）
  3. 在命盘中找到该星曜所在的宫位，即为化禄/化权/化科/化忌的落宫
  4. 在落宫中标记该星曜的化曜类型（如"廉贞化禄"）

需要计算三层四化：
  1. 生年四化：由出生年天干决定（年干四化影响一生）
  2. 大限四化：由当前大限宫位的天干决定（该大限十年内生效）
  3. 流年四化：由当年流年天干决定（该流年内生效）

四化显示规则：三层四化并列显示，用不同前缀区分层级（"年"=生年、"限"=大限、"流"=流年）。
同一星曜可同时承载多层四化（如"紫微 化科(年) 化权(限)"），以不同颜色标注区分。
若某星曜同时被生年和大限/流年化忌，以"化忌"红色高亮显示并加粗，提示需重点关注。
```

### 3.8 星曜亮度（庙旺得利平陷）

```
每颗十四主星在十二宫有固定的亮度等级，需内置完整的亮度查询表：

亮度等级从高到低：庙 → 旺 → 得 → 利 → 平 → 不 → 陷

示例数据结构：
starBrightness = {
  '紫微': { '子':'旺', '丑':'庙', '寅':'得', ... },
  '天机': { '子':'庙', '丑':'得', '寅':'利', ... },
  ...
}

所有十四主星的完整亮度表需内置。
```

### 3.9 大限排法

```
大限起运岁 = 五行局数字（水二局=2, 木三局=3, 金四局=4, 土五局=5, 火六局=6）
每步大限 = 10年

大限顺逆：
  阳男阴女 → 顺行（命宫起，沿地支顺时针方向逐宫推进）
  阴男阳女 → 逆行（命宫起，沿地支逆时针方向逐宫推进）

  阳年天干：甲、丙、戊、庚、壬
  阴年天干：乙、丁、己、辛、癸

当前大限判断：
  根据用户当前虚岁，匹配落在哪个大限区间。
  虚岁 = 当前年份 - 出生年份 + 1（按农历年算）

大限宫位的天干：
  由大限所在地支和年干关系，通过五虎遁推算。
```

### 3.10 流年排法

```
流年命宫：
  流年地支即为流年命宫所在的地支位置。
  例：2026年为丙午年，流年命宫在午宫。

流年十二宫：
  从流年命宫起，按固定顺序（与本命十二宫排列方式相同）排列流年十二宫。
  流年命宫 → 流年兄弟 → 流年夫妻 → ... 逆时针排列。

流年四化：
  由流年天干查四化表。
```

### 3.11 命主星和身主星

```
命主星（由命宫地支决定，中州派版本，依据《紫微斗数全书》）：
  地支：子    丑    寅    卯    辰    巳    午    未    申    酉    戌    亥
  星曜：贪狼  巨门  禄存  文曲  廉贞  武曲  廉贞  文曲  禄存  巨门  贪狼  武曲
  注意：此表为对称排列（子-戌、丑-酉、寅-申、卯-未、辰-午、巳-亥两两对称）。
        部分流派在申-亥段采用不同排法（如申→武曲、酉→禄存、戌→巨门、亥→贪狼），
        实现时请以本表为准。

身主星（由年支决定）：
  地支：子    丑    寅    卯    辰    巳    午    未    申    酉    戌    亥
  星曜：火星  天相  天梁  天同  文昌  天机  火星  天相  天梁  天同  文昌  天机

以上为中州派主流版本，依据《紫微斗数全书》。命主星中"午宫为廉贞"和"辰宫为廉贞"是与其他派别的关键差异点。
```

### 4.2 每个宫格渲染的信息层（共7层）

```
┌──────────────────────────────────────────────┐

│
│ 迁移宫 巳         限34-43       ← 第1/2/3层：宫名 + 地支 + 大限年龄段
│ ──────────────────────────────

│ 天梁[庙]                        ← 第8层

│ 年 天同化禄                     ← 第14层：流年四化
│
│ ▶ 当前大限            流年兄弟宫 ← 第4层 + 第7层
└──────────────────────────────────────────────┘

详细信息项：
  1. 宫名 ——  命宫/兄弟宫/夫妻宫/子女宫/财帛宫/疾厄宫/迁移宫/交友宫/事业宫/田宅宫/福德宫/父母宫

  3. 大限年龄段 —— 格式"限XX-XX"，右侧显示，蓝色小字
  4. 当前大限标记 —— 仅当前所行大限的宫格显示，左下角"▶ 当前大限"标记，整个宫格加高亮底色
  5. 命宫标记 —— 仅命宫显示，右上角红色"命"字标签
  6. 身宫标记 —— 仅身宫显示，右上角蓝色"身"字标签
  7. 流年宫名 —— 右下角紫色小字，如"流年命宫""流年财帛宫"
  8. 十四主星 —— 橙色粗体，每颗后标亮度[庙][旺][得][利][平][陷]
  9. 六吉星 —— 绿色（左辅、右弼、天魁、天钺、文昌、文曲）
  10. 六煞星 —— 红色（擎羊、陀罗、火星、铃星、地空、地劫）
  11. 杂曜/辅星 —— 蓝色（禄存、天马、天刑、天姚、红鸾、天喜、天哭、天虚、华盖、孤辰、寡宿、将星、截空、旬空等）
  12. 生年四化 —— 跟在对应星曜名称后面，如"紫微 化科"，四化用独立颜色：化禄=金色，化权=橙色，化科=青色，化忌=红色
  13. 大限四化 —— 宫格底部单独一行，前缀"限"字，标注大限天干飞化落入此宫的星曜及类型
  14. 流年四化 —— 宫格底部单独一行，前缀"年"字，标注流年天干飞化落入此宫的星曜及类型
```

> - `utils/`：纯计算函数和查表工具，不依赖 Vue API，便于独立单元测试。
> - `data/`：静态数据表，导出为常量对象/数组。
> - `pages/`：路由页面入口，`ZiweiPage.vue` 仅做路由挂载，实际业务渲染由 `components/business/ziwei/` 下的组件完成。

## 七、关键类型定义

```typescript
// 地支
type DiZhi = '子' | '丑' | '寅' | '卯' | '辰' | '巳' | '午' | '未' | '申' | '酉' | '戌' | '亥'

// 天干
type TianGan = '甲' | '乙' | '丙' | '丁' | '戊' | '己' | '庚' | '辛' | '壬' | '癸'

// 时辰（地支 + "时"字后缀）
type ShiChen = '子时' | '丑时' | '寅时' | '卯时' | '辰时' | '巳时' | '午时' | '未时' | '申时' | '酉时' | '戌时' | '亥时'

// 宫名
type GongName =
  | '命宫' | '兄弟宫' | '夫妻宫' | '子女宫' | '财帛宫'
  | '疾厄宫' | '迁移宫' | '交友宫' | '事业宫' | '田宅宫'
  | '福德宫' | '父母宫'

// 星曜亮度
type Brightness = '庙' | '旺' | '得' | '利' | '平' | '不' | '陷'

// 星曜分类
type StarCategory = 'major' | 'lucky' | 'evil' | 'assist' | 'misc'

// 四化类型
type HuaType = '化禄' | '化权' | '化科' | '化忌'

// 单颗星曜数据
interface StarInfo {
  name: string
  category: StarCategory
  brightness?: Brightness
  hua?: HuaType            // 生年四化（若该星被生年天干化）
  daxianHua?: HuaType      // 大限四化
  liunianHua?: HuaType     // 流年四化
}

// 单个宫位数据
interface PalaceData {
  gongName: GongName                          // 本命宫名
  diZhi: DiZhi                               // 地支
  tianGan: TianGan                            // 天干（由年干和五虎遁推算）
  stars: StarInfo[]                           // 所有星曜
  daxianRange: [number, number]               // 大限年龄段 [起岁, 止岁]
  isDaxianActive: boolean                    // 是否为当前大限
  isMingGong: boolean                        // 是否为命宫
  isShenGong: boolean                        // 是否为身宫
  liunianGongName?: GongName                 // 流年宫名（右下角紫色标注）
  liunianActive?: boolean                    // 是否为流年命宫
  daxianSiHua: { star: string; type: HuaType }[]   // 落入此宫的大限四化
  liunianSiHua: { star: string; type: HuaType }[]  // 落入此宫的流年四化
  changSheng?: string                        // 长生十二神
  daXianAge?: string                         // 大限年龄（如"34-43"）
}

// 出生输入数据
interface BirthInput {
  name: string
  gender: '男' | '女'
  solarYear: number
  solarMonth: number
  solarDay: number
  birthHour: number     // 0-23（24小时制）
  birthMinute: number   // 0-59
  province: string
  city: string
  longitude: number     // 经度（度）
}

// 命盘全局数据
interface ChartData {
  // 输入信息
  input: BirthInput
  gender: '男' | '女'

  // 校正结果
  trueSolarTime: Date         // 真太阳时
  shiChen: ShiChen           // 时辰名称
  solarDate: Date             // 公历日期（含真太阳时跨日校正）
  isCrossDay: boolean        // 是否跨日

  // 农历信息
  lunarYear: string          // 农历年干支，如"壬寅年"
  lunarYearGan: TianGan     // 年干
  lunarYearZhi: DiZhi       // 年支
  lunarMonth: number         // 农历月（含闰月标识，如 5 或 5.5 表示闰四月）
  lunarDay: number           // 农历日
  isLeapMonth: boolean       // 是否闰月

  // 命盘要素
  wuXingJu: string           // 五行局名称（水二局/木三局/金四局/土五局/火六局）
  wuXingJuNum: number        // 五行局数字
  mingZhuStar: string        // 命主星
  shenZhuStar: string        // 身主星
  mingGongZhi: DiZhi         // 命宫地支
  mingGongIndex: number      // 命宫地支索引（0-11，子=0）
  shenGongZhi: DiZhi         // 身宫地支
  shenGongIndex: number      // 身宫地支索引
  shenGongName: GongName     // 身宫对应的宫名
  qiYunAge: number           // 起运岁
  daxianDirection: '顺行' | '逆行' // 大限顺逆
  isYangYear: boolean        // 是否阳年（影响大限顺逆）

  // 十二宫数据（按地支索引0-11，子=0，丑=1，...）
  palaces: Record<number, PalaceData>

  // 三层四化
  birthSiHua: { type: HuaType; star: string; palace: GongName; palaceIndex: number }[]
  daxianSiHua: { type: HuaType; star: string; palace: GongName; palaceIndex: number }[]
  liunianSiHua: { type: HuaType; star: string; palace: GongName; palaceIndex: number }[]

  // 流年信息
  liunianGanZhi: string      // 流年干支
  liunianGan: TianGan        // 流年天干
  liunianYear: number        // 流年（如 2026）
  liunianMingGongIndex: number // 流年命宫地支索引
  virtualAge: number         // 虚岁 = 当前年 - 出生年 + 1

  // 当前大限
  currentDaXian: {
    index: number            // 大限索引（0=第一个大限）
    startAge: number         // 起始年龄
    endAge: number          // 终止年龄
    startYear: number       // 起始公历年份
    palaceIndex: number      // 该大限落在哪一宫（地支索引）
  }
}
```

1. 用户填写表单后点击"排盘"按钮，右方实时渲染命盘
2. 命盘渲染后，鼠标 hover 宫格时有微弱高亮效果（`opacity: 0.85`，`box-shadow` 微发光）
3. 如果出生时间经真太阳时校正后时辰发生变化，在结果中明确提示用户："真太阳时校正后时辰由丑时变为寅时"
4. 当前大限宫格有金色微光底色（`rgba(240, 192, 80, 0.07)`），视觉上突出
5. 命盘下方显示图例（见下节）

## 九、注意事项

1. **子时跨日（最重要）**：23:00-01:00 的子时均跨越午夜，日柱自动切换为次日。此规则务必优先实现和测试，是整个排盘系统的第一个关键节点。
2. **闰月处理**：农历闰月前半按本月算，后半按下月算（采用中州派主流处理方式）。闰月用小数表示（如 5.5 = 闰四月后半），或单独用 `isLeapMonth` 字段标识。
3. **排盘算法顺序约束**：务必严格按 §三 中的顺序执行（真太阳时 → 农历 → 命宫 → 五行局 → 安星 → 四化），每一步的输出是下一步的输入。
4. **数据完整性**：十四主星亮度表（7等级×12宫=84条）、四化表（10条）、纳音五行表（60甲子）、安星规则表必须完整无遗漏。建议在代码中内置完整数据表，不做简化。
5. **性能估算**：纯前端计算（无网络请求），预计算数据表后，典型排盘约 **50-150ms**（含大限/流年），满足日常使用。建议用 `performance.now()` 计时监控，若超过 500ms 需优化算法或数据表结构。农历数据表（1900-2100 年，约 10-20KB 压缩后）建议编译时内联，无需懒加载。
6. **数据范围**：农历数据表覆盖 1900-2100 年，超出范围时应在 UI 给出明确错误提示（如"出生年份超出支持范围 1900-2100"），不做静默外推。
7. **时区处理**：所有 `Date` 对象内部均使用 UTC 或本地时区，输出显示时统一使用"北京时间（UTC+8）"，避免时区混淆。
8. **错误处理与边界情况**：
   - 真太阳时校正导致跨日时，UI 需明确提示用户校正前后的日期和时辰变化。
   - 城市经度缺失时，fallback 至省会城市经度，并在结果中注明。
   - 表单校验：出生日期和时间为必填项，未填写时禁用"排盘"按钮并给出提示。
   - 异常输入（如 2 月 30 日）应在公历转农历步骤前拦截，给出明确错误信息。

## 十、测试策略

排盘系统属于算法密集型应用，测试覆盖至关重要。建议采用以下策略：

### 10.1 单元测试（核心算法）

每个 `utils/` 函数和 `composables/` 逻辑均需独立单元测试，使用 Vitest：

```
测试文件结构：
tests/
├── utils/
│   ├── solarTime.test.ts          # 真太阳时校正
│   ├── lunarCalendar.test.ts      # 公历转农历
│   ├── wuHuDun.test.ts            # 五虎遁
│   ├── naYin.test.ts              # 纳音五行
│   └── starBrightness.test.ts     # 星曜亮度
├── composables/
│   ├── useZiWei.test.ts           # 排盘主逻辑
│   ├── useDaXian.test.ts          # 大限计算
│   ├── useLiuNian.test.ts         # 流年排法
│   └── useSiHua.test.ts           # 四化飞星
└── integration/
    └── fullChart.test.ts          # 完整排盘端到端测试
```

### 10.2 回归测试用例（已知命盘对照）

使用公开已知的命盘数据作为基准，验证排盘结果的完整正确性。建议至少覆盖以下场景：

| 测试场景 | 要点 |
|----------|------|
| 子时出生（23:00-01:00） | 验证跨日逻辑、日柱切换 |
| 早子时（00:00-01:00） | 验证日期+1、时辰仍为子时 |
| 闰月出生（前半/后半） | 验证闰月归属逻辑 |
| 西部城市（如喀什 75.9°） | 真太阳时校正幅度大（约-3小时），可能跨时辰甚至跨日 |
| 东部城市（如佳木斯 130.4°） | 真太阳时校正为正值 |
| 年末出生（腊月廿九/三十） | 验证农历年份边界 |
| 紫微在寅/申（紫府同宫） | 验证天府定位公式的边界情况 |
| 阳男/阴女/阴男/阳女 | 分别验证大限顺逆方向 |
| 各五行局（水二局～火六局） | 验证起运岁和紫微定位 |

### 10.3 数据完整性校验

在测试中加入静态校验，确保数据表无遗漏：
